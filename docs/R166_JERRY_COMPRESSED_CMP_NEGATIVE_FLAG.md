# R166 — JERRY compressed-sample end-of-range branch fidelity

**October 22, 2026.** Previous production baseline R165. Changed: hosted FullSynth sample handler and existing synthetic regression only.

## Original instruction evidence

Original Jaguar FullSynth DSP image mapped at `$F1B000`; source is the owner's public frozen-exact original instruction-word reconstruction `src/frozen_exact/FULSYN_OJ_frozen_exact.s` and the RE #15 Ghidra R89–R93 recovered records. No original DSP bytes are republished.

| Module | PC | Original instruction | Proven meaning |
|---|---|---|---|
| Compressed sample (type 32) | `$F1B27C` | `CMP r5,r3` | Flags from 32-bit `end - advanced_phase` |
| Compressed sample (type 32) | `$F1B280` | `JR cc20` | Continue in range when N flag clear |
| Compressed sample with envelope (type 44) | `$F1B3A4` | `CMP r5,r3` | The same 32-bit negative-flag comparison |
| Compressed sample with envelope (type 44) | `$F1B3A8` | `JR cc20` | Continue in range when N flag clear |

The intervening `LOAD` instructions do not change the arithmetic flags. The original DSP's `CMP` determines the sign bit of a wrapped 32-bit subtraction, not a C unsigned relational compare. The host incorrectly used `if (pos > end)`. R166 uses `(uint32_t)(end - pos) & 0x80000000` with defined unsigned wraparound, retaining the previous loop/release operations and bounds checks. This parallels R165's FM envelope negative-flag correction.

Atari instruction reference: https://asterick.github.io/jag-docs/reference/risc-instruction-set.html

## Synthetic regression and scope

The existing `test_host_audio.c` adds two synthetic type-32 descriptors pointing at generated bytes only. Both use a 2-byte sample region and normal master/pan gain.

- Normal phase `$00000100`, end `$00000100`: the original DSP N flag is clear, so a valid sample is audible.
- Wrapped phase `$FFFFFE00`, end `$00000100`: DSP `(end - phase) & 0xffffffff == $00000300`, N clear, so no end/restart branch. The host's safe sample-bounds check silences this deliberately unaddressable phase.
- R165's unsigned compare wrongly enters the restart branch for the wrapped case and subtracts the fabricated `$FFFFFD00` loop offset, producing a valid but unauthorized sample.

Both GCC and Clang's updated test pass under R166, while substituting the unchanged R165 audio host for R166 causes the new assertion to fail. This is a *synthetic register-state edge case*. It does not establish occurrence in normal retail music or an audible BigPEmu improvement. No game ROM, samples, wave ROM, graphics or private Ghidra database are distributed.
